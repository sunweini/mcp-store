# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the actual label strings used in this repo's issue tracker.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  | 中文含义 |
| -------------------------- | -------------------- | ---------------------------------------- | -------- |
| `needs-triage`             | `needs-triage`       | Maintainer needs to evaluate this issue  | 待分诊：维护者需评估此 issue |
| `needs-info`               | `needs-info`         | Waiting on reporter for more information | 待补充信息：等待报告者提供更多信息 |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an AFK agent  | 可交给 agent：规格完整，可无人值守执行 |
| `ready-for-human`          | `ready-for-human`    | Requires human implementation            | 需人工处理：必须由人实现 |
| `wontfix`                  | `wontfix`            | Will not be actioned                     | 不处理：不予采纳 |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string from this table.

Edit the right-hand column to match whatever vocabulary you actually use.
